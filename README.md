# 不懂 budong

一个单文件的学习工具，把教材内容整理成结构，记录错题，按遗忘曲线安排复习。

不需要服务器、账号或网络，双击 `index.html` 即可运行，数据存在浏览器本地。

## 两本书

程序本身不含内容，学科从 `packs/` 读取，打开后先在书架选书。

**微积分** 走错题本的路线：

- 导入教材目录，建立章节结构
- 录入题目，支持拍照裁剪识别与手动输入
- 题目输入支持书写样式：分数上下分层、指数写在右上、根号带括号，配一套数学键盘
- 按章节与错因统计错误分布
- 按错因设置复习间隔
- 每节整理概念、重点题型与例题

**四级备考** 走知识库的路线，不记错题：

- 听力、阅读、写作、翻译、词汇五个部分，内容已内置
- 词表类内容平铺，题目类内容折叠
- 背单词按艾宾浩斯排程：不认识 4 小时后重来、模糊降级、认识移出词卡
- 生词本与已掌握可随时回看
- 写作与翻译各有一个 AI 批改入口，提示词可改，改完存本地

## 使用

打开 `index.html`，在书架选一本：

1. 微积分：导入目录，记题，看薄弱点，按复习安排走
2. 四级：直接看知识点，或进词汇页开始背

## 内容包

`packs/*.json` 一个文件一本书。

| 字段 | 含义 |
|---|---|
| `id` | 存储命名空间，数据存在 `cuotiben.v2.<id>` |
| `name` / `tagline` | 书架上的书名与副标题 |
| `mode` | `course` 走错题本，`exam` 走知识库 |
| `labels` | 界面用词，如「章」「节」「例题」 |
| `book` | 章节结构 |
| `notes` | 每节的概念、重点题型、条目 |

节里加 `plain: true`，条目就平铺成两列而不是折叠卡。

新增一本书：复制一份包，改 `id`、`name`、`book`、`notes`，重新构建。

## 构建与校验

```bash
python3 scripts/build.py     # 把 src/ 与 packs/*.json 拼进 index.html
python3 scripts/verify.py    # 校验例题的符号计算结果
```

`packs/` 下所有包都会打进来，运行时由书架切换。校验依赖 sympy。

源码在 `src/`：`template.html` 结构、`style.css` 样式、`app.js` 逻辑。改完必须重新构建，`index.html` 是产物。

## 数据与备份

全部存在浏览器本地，不上传。清除浏览器数据、换浏览器、换设备都会丢。

说明面板里可以导出 JSON 备份，含错题、笔记、背词进度与目标；在新设备上恢复即可。

有数据但久未备份时，界面会自己弹一次提醒，点一下就能导出。

## AI

只有四级写作与翻译的批改会用到模型。地址、模型名、key 填在「AI 设置」里，key 存本机，请求直接发给你填的接口地址。

不填也能用，其余功能不依赖网络。

## 已知限制

- 拍照识别对手写体准确率有限
- 单个浏览器内数据量上限约 10GB，主要受图片影响
- 背词进度与错题各自独立，不跨设备同步
