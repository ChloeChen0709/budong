# 不懂 budong

一个单文件的错题管理工具，用于将错题归入教材章节，观察薄弱环节并安排复习。

程序不需要服务器、账号或网络，双击 index.html 即可运行。

## 主要功能

- 导入教材目录，建立章节结构
- 录入题目，支持拍照裁剪识别与手动输入
- 题目输入支持书写样式：分数上下分层、指数写在右上、根号带括号，配一套数学键盘
- 按章节与错因统计错误分布
- 按错因设置复习间隔
- 为每个章节整理知识点、重点题型、例题与课后习题

## 使用步骤

1. 打开 index.html
2. 在导入目录中粘贴教材目录，每行一条，以章节编号开头
3. 记录错题并选择错因
4. 查看薄弱点分布与复习安排

## 内容包

程序不包含学科内容。每门课程对应 packs 目录下的一个 JSON 文件，包含教材目录以及各章节的知识点、题型、例题和习题。

新增课程时，复制已有的包文件，修改 id、name、book、notes 四个字段，再指定包名执行构建。

book 中的节表示知识单元。教材类内容使用章节划分，考试类内容可使用题型划分。

## 构建与校验

```bash
python3 scripts/build.py 包名
python3 scripts/verify.py
```

校验依赖 sympy，安装命令为 pip install sympy。

源码位于 src 目录，修改后需重新构建。index.html 为构建产物，直接修改会在下次构建时被覆盖。

例题可以附带校验规则，由符号计算得出结果并与答案比对，不一致时持续集成会失败。

## 数据存储

数据保存在浏览器本地，不会上传。清除浏览器数据或更换设备会造成记录丢失。可通过说明中的下载备份导出 JSON 文件，并在新设备上恢复。

## 已知限制

- 移动端侧栏占用空间偏大
- 手写体拍照识别准确率有限
- 当前仅提供一个内容包
