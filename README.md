# 不懂 budong

单文件网页应用，不需要服务器和网络，双击 `index.html` 就能用。数据存在浏览器里。

打开是书架，目前两本。

**微积分**是错题本。导入教材目录，记题，按章节和错因看薄弱点，按间隔复习。题目支持分数、指数、根号的书写样式，配一套数学键盘。

**四级备考**是知识库，不记错题。内容已内置，听力、阅读、写作、翻译、词汇五部分，词表直接摊开看。词汇页可以背单词，按艾宾浩斯排程，认识的移出词卡，不认识的进生词本。写作和翻译各有一个 AI 批改入口，提示词能改。

## 构建

```bash
python3 scripts/build.py
python3 scripts/verify.py
```

`build.py` 读 `src/` 和 `packs/` 下的所有包，生成 `index.html`。产物要重新构建，别手改。`verify.py` 用 sympy 校验例题，需要先装 sympy。

## 内容包

`packs/` 下一个 json 一本书，主要几项：

- `id`：也用作本地存储的命名空间
- `mode`：`course` 是错题本，`exam` 是知识库
- `book`：章节结构
- `notes`：每节的内容

复制一份，改掉这几项，重新构建就能加书。

## 数据

存在浏览器的 localStorage 和 IndexedDB，换设备不会同步。说明面板里可以导出 json 备份，恢复也在那里。

久没备份的时候界面会自己提醒一次。

## AI

只有四级的批改用得到模型。key 填在 AI 设置里，存本机，请求直接发给你填的地址。其余功能不依赖网络。
